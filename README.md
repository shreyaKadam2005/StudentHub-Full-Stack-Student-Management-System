# StudentHub-Full-Stack-Student-Management-System
Full stack application

A simple Full Stack Student Management System built with React.js, Flask & MySQL.

 Features:-
 Add students
 View students
 Update student details
 Delete students
 React + Flask REST API
 MySQL database
 Tech Stack

Frontend: React.js, Bootstrap, Axios
Backend: Python, Flask
Database: MySQL

 A beginner-friendly CRUD full-stack project for managing student records.
